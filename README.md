# [Backstage](https://backstage.io)

Backstage is an open source was developed by Spotify, manage infrastructure and software service efficiently. It provides a centralized interface where development teams can access and manage resources, monitor service health, and integrate with other DevOps tools like Kubernetes, Jenkins, GitHub, and more. The platform features flexible customization, robust plugin support, and a consistent developer experience.

To start the app, run:

```sh
yarn install
yarn dev
```
